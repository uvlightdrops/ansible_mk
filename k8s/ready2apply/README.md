# ready2apply/ – Generated & Filled Manifests

This directory contains **environment-specific Kubernetes manifests**, generated by the `yaml_config_support` CLI from the overlay templates and filled with values from `group_vars/`.

## Workflow

1. **Source of Truth**: Templates in `k8s/overlays/{dev,prod,test}/` (base manifests + overlays)
2. **Value Store**: Configuration in `group_vars/all.yml`, `group_vars/env_*.yml`
3. **Generation**: Run the fill command (see below)
4. **Deploy**: All deploy scripts read from this directory (with fallback to overlays for backward compatibility)

## Generate Manifests

From `ansible_mk/` root:

```bash
# Fill templates from overlay `dev`
python3 /home/flow/dev_flow/yaml_config_support/scripts/cli_yaml_config_fill.py dev --overlay dev

# Fill templates from overlay `prod`
python3 /home/flow/dev_flow/yaml_config_support/scripts/cli_yaml_config_fill.py prod --overlay prod
```

Configuration is set in `env_wl_flowpad.py` (via `env.py` symlink):
- `outpath`: defaults to `k8s/ready2apply`
- `basedir`: absolute project path
- overlay path is built as `k8s/overlays/<overlay>`

## Deploy

```bash
# Bootstrap cluster (uses ready2apply/ with fallback to overlays)
./prepare_docker/bootstrap_cluster.sh

# Or manual deployment
scripts/deploy_manual_no_operator.sh -n weblogic
```

Both scripts automatically detect and use filled manifests from `ready2apply/`, with fallback to original overlays if not present.
