# ready2apply/ – Generated & Filled Manifests

This directory contains **environment-specific Kubernetes manifests**, generated by
`yaml_config_support` from the overlay templates and filled with values from `valuestore_dir`.

## Workflow

1. **Source of Truth**: Templates in `k8s/overlays/{dev,prod,manual,...}/`
2. **Value Store**: `valuestore_dir` (configured in `env_wl_flowpad.py`)
3. **Generation**: Run the fill command (see below)
4. **Deploy**: All deploy scripts read from this directory (with fallback to overlays)

## Generate Manifests

From `ansible_mk/` root:

```bash
cli_yaml_config_fill --overlay manual
cli_yaml_config_fill --overlay minikube
```

Configuration: `env.py` → `env_wl_flowpad.py`
- `outpath`: `k8s/ready2apply`
- `template_dir`: `k8s/overlays/<overlay>`
- `valuestore_dir`: private value store (configured in `env_wl_flowpad.py`)

## Deploy

```bash
./prepare_docker/bootstrap_cluster.sh
scripts/deploy_manual_no_operator.sh -n weblogic
```

Both scripts detect and use filled manifests from `ready2apply/`,
with fallback to original overlay manifests if not present.
